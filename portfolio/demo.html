🚀 Personal Portfolio Website

🎯 What You've Got

A complete, modern portfolio website with all the features you need to showcase your skills and experience professionally.

  • Responsive design that looks great on all devices
  • Smooth animations and interactive elements
  • Professional sections: Hero, About, Skills, Projects, Experience, Contact
  • Working contact form with validation
  • Dark mode toggle
  • SEO optimized and accessible

🚀 Quick Start

To view your portfolio:

# Option 1: Open directly in browser
Open index.html in your web browser

# Option 2: Run local server
cd portfolio
python3 -m http.server 8000
# Then visit http://localhost:8000

✏️ Customization

Make it yours by updating these key areas in index.html:

  • Hero Section: Replace "Your Name" with your actual name
  • About: Update personal description and statistics
  • Skills: Add your technical skills and tools
  • Projects: Showcase your best work with images and descriptions
  • Experience: Add your work history and achievements
  • Contact: Update email, phone, and social media links

🎨 Styling

The design uses a beautiful gradient color scheme. To customize colors, edit the CSS variables in styles/main.css:

/* Primary gradient colors */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Background gradients */
background: linear-gradient(135deg, #f5f7fa 0%, #c3cfe2 100%);

📱 Features

  • Mobile Navigation: Hamburger menu for mobile devices
  • Smooth Scrolling: Click navigation links to smoothly scroll to sections
  • Animations: Elements animate as you scroll down the page
  • Contact Form: Includes validation and success messages
  • Dark Mode: Toggle button in bottom-right corner
  • Hover Effects: Interactive cards and buttons
